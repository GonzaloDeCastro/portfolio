## Brechas por tipo de rol

### Full-Stack (target principal)
**Gaps:** TypeScript, testing, cloud deployment  
**Plan 90 días:**
1. Semanas 1–4: tests en un producto Platform (GymFlow o PresuFlow)
2. Semanas 5–8: Deploy en AWS (EC2 o ECS) o Railway/Render con IaC básico
3. Semanas 9–12: Documentar en CV y portfolio

### Backend-heavy
**Gaps:** Cloud, mensajería, observabilidad, system design  
**Plan:** Priorizar APIs con auth JWT, rate limiting, logging, y un servicio async simple.

### Energy / Industrial hybrid
**Gaps:** Mínimas técnicas — fortalecer narrativa SCADA + APIs  
**Plan:** Case study de 1 página: "De alarmas SCADA a dashboard web"
